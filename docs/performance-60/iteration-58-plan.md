# Iteration 58: Remove measured overhead from retained production paths

Exploratory and five-repeat data show parallel BFGS at the 256-variable pilot boundary costs more than it saves (separable256 one/eight about 109/148 ms in the exploratory matrix). Restore the already-tested0.15 scalar BFGS implementation and remove its unused driver pool/setters; native propagation still receives the requested budget and large-QP kernels/batch work remain parallel. Also remove cyclic inverse-lane allocation because repeated 512 comparisons were effectively flat and 1024 regressed; keep the generic dynamic independent-column schedule. Preserve all prototype source tags/raw data. Replace private prototype tests with a public 256-variable scalar/eight-thread budget solve identity test. Run full release/example suites and seven-repeat paired 256-variable confirmation before final release; re-audit the frozen release later. This is evidence-based simplification, not a claim of universal per-iteration wins.
