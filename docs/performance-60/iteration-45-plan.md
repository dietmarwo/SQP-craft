# Iteration 45: Ordered native independent-solve batch API

Add a public Rust factory-based solve_many API using explicit maximum outer workers and independent solver/model instances. The factory constructs even non-Send models on their owning worker; no model instance crosses threads. Validate settings/options and enforce outer_workers*inner_threads<=8 before any work. Return one Result per start in input order, retaining errors independently. Reuse the existing ordered Execution map; sequential default returns equivalent results. Add tests for result order, a failing start, no Send requirement and invalid budgets. Full release suites and paired native/batch harness measurements. The common benchmark still uses its preexisting model factory until later integration, so no batch-API speedup is claimed here.
