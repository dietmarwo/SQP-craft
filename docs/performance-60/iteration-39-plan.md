# Iteration 39: Explicit native model thread-budget opt-in

Expose a default no-op NlpProblem::set_threads method so expensive native propagation models can explicitly parallelize their own independent segments. NativeSqp forwards the validated budget after input validation and before grouped callbacks. Do not require Send/Sync or move the model/observer off its caller thread; the model chooses which owned numeric slices can be parallelized. Existing Rust/Python callbacks remain serial by default. Test a deliberately non-Send model with Rc state, owner-thread assertions, both backends and 8-thread configuration; invalid starts must not configure/call the model. Full release suites and paired existing-fixture timings. This creates the correct entry point for a later expensive native propagation fixture.
